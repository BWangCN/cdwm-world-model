# Drop 世界模型 · 设计说明（中文，配图）

给同事快速理解 Drop 扩散世界模型的设计。核心：物体在桌面上方释放 → 自由下落 → 撞击 → 落定，模型**想象**落定过程并预测最终停在哪。

---

## 图 1 · 一条轨迹的时间线（模型只预测后半段）

```
 释放           自由下落（跳过·确定性弹道）        接触 k0        翻滚落定（K=8 等间隔锚点）        静止
  |────────────────────────────────────────────|═══════════════════════════════════════|
 t=0           朝向不变 · 高度=闭式弹道 · 无信息      ↑冲击        a0  a1  a2  a3  a4  a5  a6  a7
                                                             ↑                              ↑
                                                        接触起始(k0)                     最终静止
                                                     (朝向首次偏离>0.5°)                 (=端点)

  模型不预测 ◄──────────────────────────────────►   模型预测这段：K=8 姿态 ◄──────────────────►
```

- **K=8 不是 8 个物理事件**；是"接触起始 k0 → 静止"之间**按时间等间隔**取的 8 个姿态快照（`linspace(k0, n-1, 8)`）。
- 只有两端是事件：**a0 = 接触起始/冲击**，**a7 = 最终静止**；中间 6 个是翻滚过程的均匀采样。
- **自由下落被跳过**：零初速释放下朝向不变、高度是闭式弹道，没有学习信号。演示里的下落是渲染时用确定性弹道补上并标注（模型不生成它）。

## 图 2 · 扩散世界模型：从初始条件"想象"落定分布

```
   输入（只有初始条件，不喂轨迹）              扩散去噪（25 步 DDIM）                 输出
  ┌───────────────────────────┐                                          ┌──────────────────┐
  │ 物体点云                    │            纯高斯噪声                     │ 8 姿态轨迹        │
  │ + 释放参数(drop_h, 释放朝向)│──cond──►  ┃▓▒░ →→→→→→→→→→→→→ ░▒▓┃ ──►    │ a0 a1 ... a6 a7  │
  └───────────────────────────┘           25 步·噪声表上等间隔·联合去噪      └──────────────────┘
                                            （整条 8 姿态一次性去噪，非逐帧自回归）

   采样 S 次（不同噪声种子）⇒ S 个不同的"想象未来"，覆盖多模态：
        future 1 ─ 瓶子往左倒 (tip)   ┐
        future 2 ─ 瓶子落回原位 (settle)├─  分布覆盖"往哪边倒"这种确定性模型答不了的问题
        future 3 ─ 瓶子落回原位        │
           ⋮                          │
        future S ─ 瓶子往右倒 (tip)    ┘
```

- **喂进去的不是轨迹步**，是**初始观测**（点云 + 释放参数）——"给初始条件预测未来"，不是"给前 N 步预测后 M 步"。
- **两种"步"别混**：轨迹姿态 = **8 个**（按时间等间隔）；扩散去噪步 = **25 步**（噪声表上等间隔的去噪迭代，与物理事件无关；训练用 1000 步 DDPM，推理用 25 步 DDIM）。
- **预测几个未来 = 旋钮 S**：扩散定义的是"未来的分布"，采样几次就有几个未来。实际用过 **S=4（指标）、S=8（分叉探针）、S=16（演示，每行渲染 2 个）**。这就是它 vs 确定性模型的根本区别（后者只能给 1 个未来）。

## 图 3 · 数据：模型输入=点云；物理碰撞几何=mesh 的 CoACD

```
  物体形状                            世界模型输入            物理仿真碰撞几何（生成数据用）
  ┌──────────┐   观测/扫描   ┌──────────┐              ┌──────────────────────────────┐
  │ 真实物体  │────────────► │ 点云(准确) │─►WM 输入      │ 单凸包  → 丢掉凹形（早期Gate B限制）│
  └──────────┘               └────┬─────┘              │ CoACD  → 一组凸块·忠实凹形(需mesh) │
                                  │  (裸点云不能直接碰撞) └──────────────────────────────┘
                                  └─重建 mesh + CoACD ─► 覆盖"只有点云"的物体(可行但更噪·后续)
```

- **模型输入本来就是点云**（准确表面）；问题只在**物理**：引擎只能碰凸几何，裸点云不能直接仿真。
- 单凸包丢凹形（= scope 限制）；**CoACD（基于 mesh）忠实**，Item 1 已验证机制在忠实几何下依然成立（甚至更强）。
- 想覆盖只有点云的 60 个物体：**点云→重建 mesh→CoACD**，可行但重建更噪，是后续方向。**CoACD 本身做得好，瓶颈是 mesh 覆盖率（仅 29 个）**。

## 一页总结 · 名词
- **CDWM 家族**：Grasp（H=32 闭合轨迹）、Slip（K=10 提起）、**Drop（本任务）**。
- **Drop 各线**：端点基线 → 轨迹监督(traj_k8) → **语料扩散 rollout(想象落定,分布式)** → Gate B(隐藏质心分布) → 跨物体迁移 → 物理密度 → 两个扩展。
- **CoACD**：近似凸分解，把凹 mesh 拆成凸块，让刚体仿真忠实碰撞凹形。
- **Amortized encoder（摊销编码器）**：想用一次前向从观测直接预测质心，替代逐次跑世界模型；结果是**有信息量的负结果**（学得到几何先验，学不到随观测自适应）。
