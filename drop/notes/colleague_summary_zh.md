# CDWM Drop 世界模型 · 同事简报（中文，要点版）

一句话：接触动力学世界模型的 **Drop 任务** —— 物体在桌上方释放 → 自由下落 → 撞击 → 落定，模型预测**最终停在哪个稳定姿态 / basin**。已推送 GitHub（`BWangCN/cdwm-world-model`，分支 `restructure-common-grasp-drop`）。

---

## 一、相比 HuggingFace v1 数据集，我们做了什么改动（核心）

### 1. 数据：从 80 物体语料 → 我们自建的 88 物体 Gate B 集
- **相似**：都用同一套 grasp 物体高斯簇点云作条件；任务形式一致（释放→下落→撞击→落定）。
- **不同**：
  - **物体集不同**：语料 **80 唯一物体**（108 物体×配置，均匀密度、自然释放）；我们 **90 生成 / 88 使用**（排除 2 个 hammer 变体），从 ~171 grasp 宇宙里挑 **CoM 敏感物体**。**两套只重叠 17 个**（非 hammer 口径 16），73 个是我们独有。
  - **质心 CoM**：语料是**均匀密度 → 质心固定在几何中心**（无多样性）；我们**每个 episode 采一个不同的隐藏质心**（沿主轴偏移 ±0.35·半轴，质量/惯量不变、只挪质心）→ 有质心多样性可研究。
  - **释放方式**：语料是自然释放（小倾角、形状主导、多数落回）；我们是**近边界释放**（从稳定姿态朝"两个稳定姿态之间的临界脊"倾 15–55°，此处往哪倒最不确定）。
  - 注：Drop 任务**没有夹爪**，"释放"=松手丢下；近边界指释放**朝向**靠近翻倒临界点，与抓取无关。
- **术语**："Gate B" 是我们分阶段计划的里程碑代号（Gate A：值不值得做 → A.5：4 个压力测试 → **B：建质心感知的分布式 drop WM**），不是语料的子集。
- 详见 `gate_b_objects_zh.md`（88 物体表 + 两套物体宇宙对照）。

### 2. 模型：从单点端点 → 扩散世界模型"想象"落定分布
- **喂初始条件**（点云 + 释放参数），不喂轨迹步；**预测 K=8 个"接触→落定"姿态锚点**（按时间等间隔；a0=接触起始/冲击，a7=最终静止）。
- **自由下落被跳过**（零初速释放→朝向不变、无信息）；演示里的下落用确定性弹道补上并标注。
- **两种"步"别混**：轨迹姿态 **8 个**（时间等间隔）vs 扩散去噪 **25 步 DDIM**（噪声表等间隔；训练 1000 步 DDPM），整条 8 姿态一次性联合去噪。
- **预测几个未来 = 旋钮 S**：扩散给的是"未来的分布"，采样几次就有几个未来（用过 S=4/8/16）；这是它 vs 确定性模型的根本区别（后者只能给 1 个未来）。
- 详见 `drop_wm_explained_zh.md`（含 3 张示意图）。

### 3. 几何：从点云单凸包 → mesh 的 CoACD 端到端
- 世界模型输入一直是**点云**；但**物理引擎只能碰凸几何**，裸点云不能直接仿真。
- 我们早期 Gate B 用点云**单凸包**（丢凹形，= 一个 scope 限制）；**Item 1** 改成 mesh 的 **CoACD 凸分解** + 模型输入从**同一 mesh 表面重采样**（几何一致），验证机制在忠实几何下仍成立。

## 二、主要结果（都显著、通过稳健性检验、Codex 审核）
- **基线 & 分布式 Gate B**：分布 ≫ 单点（NLL +0.53 显著）；隐藏质心**有因果作用**（三种独立方式）；扩散模型**校准好**（ECE 0.015 vs 单点 0.227）。
- **跨物体迁移**：几何锚定的质心 latent 能迁移到**没见过的物体**（NLL 0.495 vs no_latent 0.679）；抽象编码不迁移。
- **★ Item 1（CoACD 端到端几何）**：忠实几何下机制**依然成立、甚至更强** —— 分布>单点 **+0.355** 显著(7/7)；grounded>no_latent **+0.245** 显著(7/7，比单凸包的 +0.184 更大)；grounded 还显著优于 abstract(+0.212) 和错误质心对照 shuffled(+0.236) → 要的是**正确的几何锚定质心**。
- **★ Item 2（从观测推质心，去掉 oracle）**：用冻结世界模型当似然做贝叶斯推断，观测越多预测越准 —— NLL 0.678→0.566；配对增益 k=0→8 **+0.111** 显著(17/19)；后验随观测收敛；边缘化优于单点、更好校准；无泄漏。
- 详见 `colleague_update_extensions.md`（两个扩展的完整数据，中英对照）。

## 三、我们排除的方案（有信息量的负结果）
- **学习式摊销编码器**（一次前向直接从观测预测质心）：能学到有用的几何先验，但**随观测不自适应**（k=0→8 增益 −0.003，不显著）。结论：这个逆问题不易摊销，**解析式贝叶斯才是有效方法**——反而强化了 Item 2 的核心贡献是"自适应"。
