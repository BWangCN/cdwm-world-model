# Drop 阶段 · 物体密度 / 质心多样性计划（同事简报，2026-07-21）

> 面向同事的简明版。完整英文计划见 [`drop_density_todo.md`](drop_density_todo.md)；数据集分析见 [`drop_phase_log.md`](drop_phase_log.md)。
> 已自定 → Codex 评审（会话 `019f8664`）→ 收敛确认。分支 `drop`。

## 背景与动机
- Drop 数据集用 MuJoCo 生成，物体假设**均匀密度**（71/80 用 400 kg/m³ × 凸包体积代理，仅 9 个 YCB 有实测质量）。
- 后果：**没有质心（CoG）多样性**可供深入研究 —— 每个物体的质心都落在其几何中心。

## 关键物理事实（整个计划的支点）
- MuJoCo `inertiafromgeom` + 单一均匀密度 ⇒ **质心 = 凸包组合的体积中心，与密度数值无关**。
- 所以「把每类物体的均匀密度改成真实值」只提升**质量真实性**，**不会**产生任何质心多样性（README / admission_matrix 已印证：质量只影响静止穿透尾部，不改变任何 admit/reject 判定）。
- **杠杆**：每个物体已被 **CoACD 分解成 ≤24 个凸包**。给不同凸包赋**不同密度**即可移动质心，**无需新几何**（如锤子＝重锤头凸包＋轻手柄凸包；瓶子＝重底＋轻身）。

## 密度阶梯（决策分叉）
- **L1** 均匀真实密度：质心不变 → 仅质量真实，无 CoG 信号。
- **L2** 固定非均匀（每物体内部质量图固定）：质心跨物体有差异，但对物体身份仍是确定函数 → 可被点预测器学会，**无隐变量**（与 grasp-rigid 结论相同）。
- **L3** 随机非均匀（每 episode 采样隐藏质心，点云看不出）：**真正的隐变量** → 偶然多模态 → 静止位姿对固定观测是一个**分布**。

## 收敛后的定位（Codex 评审要点）
- **目标 = L3，但必须锚定在真实隐物理状态**（液面 / 内部配重 / 工具头柄材料 / 每物体合理质量图），不能是任意随机（否则被审稿人视为人造不确定性）。
- **诚实定位**：单次「点云 → 最终位姿」是**偶然不确定性的校准分布预测**（是 slip-MDN 结果的直接延续），**不是** belief-state / system-ID（后者需要序列 / 交互式观测来更新）。不要过度声称。
- **旋钮**：逐凸包异质密度 = **主**旋钮（物理、复用 CoACD、质心/惯量由 MuJoCo 自洽耦合）；显式 `<inertial>` 质心偏移 = **消融/对照**旋钮。

## 执行顺序（先便宜地证伪，且不占用主线）
- **Gate A（先做，判断值不值得建）**
  - T1 收集真实质量 → `object_mass.csv`（24 个 YCB 有公开实测 + 56 个 GSO 有 metadata；缺的用材料密度先验推算并标注置信度）。
  - T2 仅为试点物体准备 CoACD 的 MJCF（向同事要 `assets573`，或用我们已有的 mesh 经 CoACD + obj2mjcf 重建）。
  - T3 摸清 MuJoCo 密度机制（`<geom density>` 主 / `<inertial>` 消融），写一个 `test_density.py` 验证改凸包密度确实移动 `body_ipos`。
  - **T4 A/B 小试点（go/no-go）**：选 ~4–6 个高杠杆形状（锤/工具、瓶/罐、不对称凹形、扁平易倒），扫合理质心图，重投几个释放位姿，测**basin 跃迁率 + 终态熵**（均匀 vs 偏移）。**效果弱 → 停，不建全量。**
- **Gate B（仅当 Gate A 证明质心确实改变结果）**
  - T5 全量逐凸包密度图（类别模板 × 凸包位置，锚定真实隐状态；L3 每 episode 采样）。
  - T6 全量重仿真（同事 corpus-v1 harness，或放大已验证的小 harness）。
  - T7 CoG-aware WM：几何 + 释放参数 → 静止位姿的**校准分布**（能量分数/CRPS，绝不只报点估计）。

## 风险
- 最大风险（Codex 指出）：在证明质心确实显著改变结果之前，花数周重仿真。很多物体的稳定 basin 由形状/接触主导，质心扰动可能只带来边际变化 → 所以 **A/B 试点必须先行**。
- 本线**并行且门控**，不阻塞 baseline drop WM（结果分类 + 静止位姿预测）这条主线。

## 结果总结（Gate A + A.5 全部完成，完整英文报告见 [`../density/REPORT.md`](../density/REPORT.md)）

- **T3 机制已证实**（`density/test_density.py`）：均匀密度 → 质心恒在几何中心，与密度值无关；逐凸包异质密度 → 质心移动到质量加权中心。
- **T1 真实质量**：24 个 YCB 全部对上公开质量（elpis-lab/ycb_dataset）；代理质量对 18/24 偏差 >15%（锤子差 2 倍）。
- **T4 试点（锤子）**：语料的稳定位姿 + 小倾角采样下，83mm 质心偏移带来 **0%** basin 改变（形状主导）；但**接近临界（立起来）时 100%**。
- **语料审计**：15.4 万有效 episode 中仅 **2.3%** 跨到新 basin（net_rot 中位数 7.7° ≈ 释放倾角）→ 语料按当前采样是形状主导的。倾覆集中在 ~5 个瘦高/不对称物体（cracker_box 40%、Android 45%、Razer 鼠标 44%）；72/80 物体 <1%；瓶罐类 0%。
- **V1+V2（解析，558 物体）**：质心敏感性是**形状属性** —— 扁平物（盘子/盒子）robust（TV≈0.02），瘦长/不对称（勺/钳/鼠标/公牛）sensitive（TV≈0.9–1.0）；中位 TV 0.28，28% >0.5 → **不只是锤子**。**关键：cracker_box 语料里倾覆 40% 但质心 robust → 倾覆率 ≠ 质心敏感性**（按敏感性排名选物体，别按倾覆率）。
- **V3（锤子）**：质心敏感性在 basin 内 ~0，在**稳定位姿的鞍点处骤增**（θ≈95°：92% basin 分歧，中位 179.6°）→ 面向鞍点的边界采样器能找到质心决定性的位姿。
- **V4（锤子）**：鞍点处质心作为**隐变量**采样时，固定观测下静止位姿**多模态**（3 个 basin [0.76,0.23,0.01]）；分布式预测比点预测好 **1.06 nats NLL** → 需要分布式/belief-state WM（drop 版的 slip-MDN）。

**结论**：质心多样性值得做，但是一个**有针对性的独立贡献**（质心敏感形状 × 近边界释放 → 多模态 → 分布式 WM），不是改现有语料；排在 baseline drop WM **之后**，不占主线。**下一步**：把 V3/V4 的动力学验证扩展到 2–3 个物体（不只锤子）+ 修正解析工具里近球体的退化标记。
